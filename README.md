👨‍💼 Employee Dashboard

A simple and responsive Employee Dashboard built using HTML, CSS, and JavaScript.
This dashboard provides an overview of employee statistics such as total employees, average salary, and highest salary using a clean and user-friendly interface.

🌐 Live Demo

🔗 https://employee-dashboard-nine-flax.vercel.app/

📖 Project Overview

The Employee Dashboard helps visualize basic employee information in a structured dashboard layout. It displays key employee metrics and provides a quick overview of organizational data.

The project is built using pure frontend technologies without frameworks, making it lightweight and beginner-friendly for learning web development.

✨ Features
📊 Dashboard Cards

👥 Display Total Employees

💰 Display Average Salary

🏆 Display Highest Salary

📋 Employee Table

Shows employee details clearly

Organized structure for easy reading

Works on desktop, tablet, and mobile

User-friendly interface
